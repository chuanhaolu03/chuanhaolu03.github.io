# Chuanhao Lu Academic Website

This folder contains the complete source and public assets for Chuanhao Lu's academic website.

- `app/`: website source
- `cv/Chuanhao_Lu_CV.tex`: editable academic CV source
- `public/Chuanhao_Lu_CV.pdf`: downloadable CV

The website lists research titles, coauthors, and publication status without hosting manuscript PDFs.

Pushes to `main` are automatically built and published with GitHub Pages.
